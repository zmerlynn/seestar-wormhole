# References

Use these pages when you script seestar-wormhole or need an exact flag, rule,
file format or log line. To get something done, start from the
[documentation home](../README.md).

- [Connection command reference](connection-cli.md): the app's executable,
  `seestar-wormhole-cli proxy`, `discovery` and `licenses`, global flags, exit
  codes, logs, device selection, release checks, containers and Windows.
- [File command reference](files-cli.md): `seestar-wormhole-cli sync`, `find`,
  `browse` and `delete`, with their flags, logs and exit codes.
- [App settings and internals](app-settings.md): where the app keeps its
  settings, the `config.json` and `copy.json` formats, file permissions, the
  control page and the window engine's data.
- [Selection and copy history](selection-and-history.md): the patterns that
  choose files, the copy history and its format, and the locks that keep a
  copy and a delete apart, for the app and the file commands alike.
